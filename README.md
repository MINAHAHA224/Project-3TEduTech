## 🌟 Giới thiệu dự án

**3T EduTech** không chỉ là một nền tảng E-learning thông thường. Đây là một giải pháp toàn diện được thiết kế để giải quyết những thách thức lớn nhất của giáo dục trực tuyến: sự thiếu tương tác, thiếu cá nhân hóa và rào cản thanh toán. Bằng cách tích hợp các công nghệ tiên tiến như **AI, Đồ họa 3D, và hệ thống thanh toán đa kênh**, chúng tôi mang đến một trải nghiệm học tập đột phá, hấp dẫn và không giới hạn.

## ✨ Các tính năng nổi bật

### 👨‍🎓 Dành cho Học viên
- **Học tập Tương tác 3D:** Trực quan hóa các khái niệm phức tạp bằng mô hình 3D có thể xoay, phóng to, thu nhỏ.
- **Trợ lý AI Tutor:** Giải đáp thắc mắc 24/7, hiểu ngữ cảnh bài học để đưa ra câu trả lời chính xác.
- **Lộ trình học Cá nhân hóa:** AI phân tích kết quả và gợi ý các bài học cần củng cố.
- **Thanh toán Không biên giới:** Hỗ trợ MoMo, VNPay, PayPal, Stripe và cả **Cryptocurrency**.
- **Hệ thống Chứng chỉ:** Tự động cấp chứng chỉ (dạng PNG & PDF) sau khi hoàn thành khóa học.
- **Đa ngôn ngữ & Tiền tệ:** Giao diện và giá cả tự động điều chỉnh theo khu vực người dùng.

### 👩‍🏫 Dành cho Giảng viên
- **Quản lý Nội dung Toàn diện:** Tạo khóa học với nhiều dạng bài học (Video, Text, Quiz, 3D).
- **API "Sync Curriculum":** Cập nhật toàn bộ cấu trúc khóa học chỉ trong một lần gọi API, đảm bảo tính nhất quán.
- **Luồng cập nhật an toàn:** Clone và chỉnh sửa khóa học đã xuất bản mà không ảnh hưởng đến học viên hiện tại.
- **Quản lý Tài chính Minh bạch:** Dashboard theo dõi doanh thu, số dư, và lịch sử giao dịch chi tiết.
- **Hệ thống Rút tiền:** Dễ dàng tạo yêu cầu và theo dõi trạng thái chi trả.

### 👑 Dành cho Admin
- **Dashboard Tổng quan:** Theo dõi sức khỏe toàn hệ thống (doanh thu, người dùng, khóa học).
- **Hệ thống Phê duyệt:** Quy trình chuyên nghiệp để duyệt khóa học, bản cập nhật, và yêu cầu rút tiền.
- **Quản lý Linh hoạt:** Toàn quyền quản lý người dùng, vai trò, danh mục, và các mã giảm giá.
- **Cài đặt Hệ thống Động:** Dễ dàng thay đổi các quy tắc kinh doanh (phí hoa hồng, bật/tắt cổng thanh toán) mà không cần can thiệp vào code.

## ⚙️ Hướng dẫn Cài đặt & Khởi chạy

### 📋 Yêu cầu
Trước khi bắt đầu, hãy đảm bảo bạn đã cài đặt các công cụ sau:
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (v18.x trở lên)
- [Python](https://www.python.org/) (v3.10 trở lên)
- [MS SQL Server](https://www.microsoft.com/en-us/sql-server/sql-server-downloads) & [SQL Server Management Studio (SSMS)](https://docs.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms)
- [Visual Studio Code](https://code.visualstudio.com/) hoặc một IDE tương tự.

### 🚀 Bắt đầu

Làm theo các bước sau để cài đặt và chạy dự án trên máy cục bộ.

#### 1. Clone Repository
```bash
# Thay <your-repository-url> bằng URL đến repo của bạn
git clone <your-repository-url>
cd <your-project-directory>
```

#### 2. Cài đặt Cơ sở dữ liệu
1.  Mở SSMS và kết nối tới SQL Server của bạn.
2.  Mở file script `DatabaseScript.sql` (nằm ở thư mục gốc của dự án).
3.  Thực thi (Execute) toàn bộ script để tạo database `ThreeTEduTechLMS` và các bảng cần thiết.

#### 3. Cài đặt Biến môi trường
1.  Trong mỗi thư mục con (`Backend`, `Frontend`, `AI`), tìm file `.env.example`.
2.  Tạo một bản sao của mỗi file và đổi tên thành `.env`.
3.  Mở các file `.env` và điền các thông tin cần thiết (thông tin CSDL, API keys, JWT secret...).

> **Lưu ý quan trọng:** File `.env` chứa các thông tin nhạy cảm. Hãy chắc chắn rằng file `.gitignore` của bạn có dòng `.env` để không vô tình đưa các thông tin bí mật này lên kho chứa Git.

#### 4. Khởi chạy Backend
```bash
# Di chuyển vào thư mục Backend
cd Backend

# Cài đặt các dependencies
npm install

# Khởi chạy server ở chế độ development
npm run dev
```
Backend sẽ chạy tại `http://localhost:5000` (hoặc cổng bạn đã cấu hình).

#### 5. Khởi chạy Frontend
```bash
# Mở một terminal mới, di chuyển vào thư mục Frontend
cd Frontend

# Cài đặt các dependencies
npm install

# Khởi chạy ứng dụng React
npm run dev
```
Truy cập ứng dụng tại `http://localhost:8080` (hoặc cổng do Vite cung cấp).

#### 6. Khởi chạy AI Service
```bash
# Mở một terminal mới, di chuyển vào thư mục AI
cd AI

# (Đề xuất) Tạo một môi trường ảo Python
python -m venv venv
source venv/bin/activate  # Trên Windows dùng: venv\Scripts\activate

# Cài đặt các dependencies
pip install -r requirements.txt

# Khởi chạy AI server
uvicorn main:app --reload
```
Dịch vụ AI sẽ chạy tại `http://localhost:8000`.

Bây giờ, toàn bộ hệ thống đã sẵn sàng hoạt động!
